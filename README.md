# 간단 프롬프터 (Teleprompter)

## GitHub로 자동 EXE 빌드하기 (윈도우 PC 없어도 됨)
이 폴더에는 GitHub Actions 설정(`.github/workflows/build.yml`)이 들어있어서,
**GitHub에 올리기만 하면 GitHub의 윈도우 서버가 자동으로 EXE를 빌드**해줍니다.

### 1) 새 저장소 만들고 파일 올리기
1. https://github.com 에서 로그인 → 오른쪽 위 **+** → **New repository**
2. 이름 입력(예: `teleprompter`) 후 **Create repository**
3. 이 폴더 안의 파일 전체(`teleprompter.py`, `requirements.txt`, `.gitignore`,
   `.github/워크플로우 폴더 포함`, `README.md`)를 그 저장소에 업로드
   - 웹에서 하는 방법: 저장소 페이지 → **Add file → Upload files** → 폴더째 드래그 앤 드롭 → **Commit changes**
   - 또는 git 명령어(터미널)로:
     ```
     git init
     git add .
     git commit -m "초기 커밋"
     git branch -M main
     git remote add origin https://github.com/내계정/teleprompter.git
     git push -u origin main
     ```

### 2) 자동 빌드 확인
- 업로드(push)하면 자동으로 빌드가 시작됩니다.
- 저장소 상단 메뉴의 **Actions** 탭 → 가장 최근 실행(`Build Windows EXE`) 클릭
- 초록 체크(✅) 뜨면 완료. 페이지 아래 **Artifacts** 항목의
  **Teleprompter-windows-exe**를 클릭하면 zip으로 다운로드됩니다.
  (안에 `Teleprompter.exe`가 들어있어요)

### 3) 정식 버전(릴리스)으로 받고 싶다면
태그를 `v1.0.0` 형태로 붙여서 push하면, **Releases** 페이지에 자동으로
`Teleprompter.exe`가 첨부된 릴리스가 생성됩니다.
```
git tag v1.0.0
git push origin v1.0.0
```

### 4) 코드 수정 후 다시 빌드하려면?
`teleprompter.py`를 고치고 다시 `git push`만 하면 Actions가 알아서 재빌드합니다.
(수동으로 돌리고 싶으면 Actions 탭 → 워크플로우 선택 → **Run workflow** 버튼)

## (참고) 내 컴퓨터에서 직접 빌드하고 싶다면
GitHub 없이 로컬 윈도우 PC에서 바로 만들 수도 있습니다.
1. 파이썬이 없다면 https://www.python.org 에서 설치
   (설치 화면에서 **"Add python.exe to PATH"** 꼭 체크)
2. `teleprompter.py`, `build_exe.bat` 두 파일을 같은 폴더에 둡니다.
3. `build_exe.bat`을 더블클릭 → 자동으로 필요한 도구 설치 후 빌드됩니다.
4. 완료되면 같은 폴더의 `dist` 폴더 안에 **Teleprompter.exe**가 생성됩니다.
   → 이 파일만 있으면 파이썬 없이도 바로 실행됩니다. (원하는 곳에 복사해서 사용하세요)

## 페이퍼로지 고딕 폰트
프로그램 자체에는 폰트를 내장하지 않았습니다. 기본 폰트로 "Paperlogy"를 자동 선택하도록
되어 있지만, **PC에 해당 폰트가 설치되어 있어야** 목록에 나타나고 적용됩니다.
설치 안 돼 있으면 자동으로 맑은 고딕 등으로 대체됩니다.
(눈누 사이트 등에서 페이퍼로지 폰트를 내려받아 설치 → ttf파일 더블클릭 → "설치" 하면 됩니다.)

## 프로그램 사용법
| 기능 | 위치 |
|---|---|
| 글자크기 변경 | 상단 툴바 "크기" 스핀박스 |
| 폰트 변경 | 상단 툴바 "폰트" 드롭다운 (시스템에 설치된 폰트 전체 목록) |
| 내용 편집 | 화면 중앙 큰 텍스트 창에 직접 입력 |
| 창 크기 조절 | 창 테두리를 드래그 (일반 윈도우 창과 동일) |
| 전체화면 | 툴바 "전체화면" 버튼 또는 F11 (Esc로 해제) |
| 상단 고정 | 툴바 "항상 위" 체크박스 |
| 여러 원고(탭) | "+ 탭 추가" / "탭 이름변경" / "탭 닫기" |
| 하이라이트(형광펜) | 강조할 부분을 드래그로 선택 → 툴바의 색상 버튼 클릭 |
| 글자색 | 선택 후 "글자색" 색상 버튼 클릭 |
| 서식 지우기 | 선택 후 "서식지우기" |
| 행동지시 표시 | 원고 안에서 한 줄의 맨 앞에 `▶` 를 붙이면, 그 줄은 원고에서 사라지고 오른쪽 "행동지시" 패널에 표시됩니다. 스크롤해서 그 위치에 도달하면 패널에서 자동으로 강조(선택)됩니다. 패널 항목을 클릭하면 해당 위치로 바로 이동합니다. |
| 자동 스크롤 | "▶ 자동스크롤" 버튼으로 시작/정지, "속도" 슬라이더로 빠르기, "간격(줄)" 스핀박스로 한 번에 스크롤되는 줄 수 조절 |
| 수동 스크롤 | 키보드 ↑ / ↓ (간격 스핀박스 값만큼 이동) |

### 행동지시 작성 예시
```
안녕하세요, 오늘 발표를 시작하겠습니다.
▶ 미소 지으며 잠시 멈춤
이번 분기 실적에 대해 말씀드리겠습니다.
```
위처럼 입력하면 원고 화면에는 "▶ 미소 지으며 잠시 멈춤" 줄이 보이지 않고,
오른쪽 패널에 `[2] 미소 지으며 잠시 멈춤` 형태로 표시됩니다.

## 리눅스/맥에서 바로 테스트하고 싶다면
```
python3 teleprompter.py
```
(파이썬과 기본 tkinter만 있으면 실행됩니다. 별도 설치 불필요)
